# FACT
Free Autonomous Coding Technology - have your own claude code.


## Modes
**Fast**: it just executes the code with no deep understanding of the problem.

**Normal**: in this mode it gathers enough context to start and is worthy of trust with no double-checking.

**Deep**: here, it reasons in every step and optimizes itself as much as possible but it is a token eater.

**Design**: this mode doesn't write code, it just asks you questions, verifies and discusses with you the ideas and ends the session with a file of the architecture.

## Useful Commands
1. `/checkpoint`: this make a summary of everything in compact md files and save the session in a file so that you can kick start next time with all needed context.
2. `/compact`: this makes a summary of everything but only in a single file, it is a minor version of `/checkpoint`
3. `/clear`: this starts a new session in the same window you opened.
